# Hong Pick 6.6.2

기존 Flask + HTML/CSS/JS 프로젝트를 확장한 개인용 주식 대시보드입니다.

## 실행·배포

```sh
pip install -r requirements.txt
python server.py
```

기본 운영 주소: https://jho971031-cloud.github.io/Hongpick/

GitHub Pages가 화면과 수집된 JSON을 직접 제공합니다. Python 수집기는 `.github/workflows/pages.yml`의 GitHub Actions에서 30분 간격으로 실행하고 공개 파일만 Pages에 배포합니다. 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다. 최초 실행은 Actions → Collect data and publish Hong Pick → Run workflow로 시작할 수 있습니다. 새 코드를 main에 올려도 자동 실행됩니다. 예약 실행은 지연될 수 있으며 공개 저장소는 60일간 활동이 없으면 예약 실행이 비활성화될 수 있습니다.

홈·거래대금·거장·공시·심리·관심종목 및 수집된 종목 차트는 Render 없이 동작합니다. 수집 범위는 한국/미국 TOP50, 운용사별 주요 10개 보유종목, 검증된 Trump 거래와 주요 검색 종목입니다. 미수집 종목은 화면 위 **미수집 종목 API 보완**이 켜져 있을 때만 기존 Render API를 호출합니다. 이 옵션을 끄면 Render 요청 없이 운영하며 없는 데이터는 없다고 표시합니다. 주식은 지연·수집 시각 기준 데이터입니다. 코인은 Binance 공개 WebSocket 연결 시 실시간 시세와 진행 중인 캔들을 표시합니다. 연결 실패·일시정지 시 수집본 또는 마지막 수신값과 연결 상태를 표시합니다. 아직 수집하지 않은 임의 종목을 즉시 조회하는 기능까지 모두 유지하려면 보조 API가 필요합니다.

기존 API 운영 주소는 https://hongpick.onrender.com/ 입니다. 기존 GitHub → Render 자동 배포를 유지합니다. Build: `pip install -r requirements.txt`, Start: `gunicorn server:app`. `/health`는 상태와 버전을 반환합니다. GitHub Pages의 지정된 Origin에만 공개 GET API의 CORS 응답을 허용합니다. 유료 서비스나 새 계정은 추가하지 않습니다. SEC 연락처는 환경변수 또는 저장소 변수 `SEC_CONTACT`로 지정할 수 있습니다. 승인된 CNN 호환 제공원은 Actions secret `CNN_FNG_URL` 또는 서버 환경변수로 설정합니다.

정적 파일 생성·미리보기:

```sh
python build_static.py --output public              # 기존 실제 스냅샷으로 오프라인 생성
python build_static.py --refresh --output public    # 제공원에서 실제 데이터 수집
python -m http.server 8000 --directory public
```

로컬 정적 미리보기는 `http://localhost:8000/?mode=static`으로 엽니다. Actions의 캐시는 날짜가 있는 실제 수집 결과를 실행 간 재사용하고 일봉·13F는 6시간, 종목 디렉터리는 24시간, 공시 목록은 1시간 기준으로 갱신합니다. 제공원 오류는 다른 메뉴에 영향을 주지 않으며 원래 수집 시각을 유지합니다. CNN 공식 제공원 실패 시 날짜와 값을 검증한 공개 수집본을 시도합니다. 수집본의 출처와 원래 업데이트 시각을 표시하며 오래된 값은 이전 데이터로 구분합니다. 어느 경로도 유효한 값을 제공하지 않으면 데이터 없음으로 표시합니다.

## 갱신과 오류 처리

Pages는 수집된 데이터를 5분 단위로 확인하며 화면에 필요한 파일만 불러옵니다. 같은 요청은 합치고 차트 라이브러리는 차트를 열 때 로드합니다. 일봉을 한 번 받으면 주봉·월봉을 브라우저에서 계산합니다. 최근 API 일봉 20개는 브라우저 IndexedDB에 보관해 연결 오류 때 이전 자료임을 표시하며 재사용합니다. 서버의 백그라운드 갱신은 최대 4개 작업으로 제한합니다. API 모드는 시세/순위90초, 일봉15분, F&G30분, 디렉터리24시간, SEC6시간, OGE문서1시간을 유지합니다.

`providers.py`: 시장 제공원·심볼 디렉터리·일봉 집계. `disclosures.py`: SEC/OGE 수집·비교. `cache.py`: 캐시. `charts.js`: 지표 계산·차트. `server.py`: 보조 API. `app.js`: 메뉴/저장/필터. `data-client.js`: 정적 데이터 우선 전송과 브라우저 캐시. `build_static.py`: 공개 파일 생성·수집. Pages 배포는 Actions에서 자동으로 생성합니다.

## Codex 픽

기존 홍픽종목과 분리된 `#codexpicks` 메뉴와 홈 TOP5. 한국·미국 거래대금 TOP50의 주식에 추세 지속, RSI 과매도 회복, 거래량 동반 252일 신고가 돌파, 주봉 빗각 지지 반등을 적용합니다. 완료 일봉만 사용하고 당일은 돌파·평균 거래량 기준에서 제외합니다. 미충족 종목을 순위 채우기에 사용하지 않습니다. 기법별 필수 조건을 통과한 뒤 가장 높은 기법 점수로 정렬하며 중복 지표 점수는 합산하지 않습니다.

### Codex 픽 규칙 2.0 (v6.6.2)

Codex 픽에서 개인 주봉 빗각의 선별 조건과 모든 채널 가점을 제거했습니다. 주봉 채널은 종목별 참고 설명만 제공하며 저항 접근과 지지 후보를 구분합니다. 위쪽 저항에 닿기만 한 상황은 매수 확인으로 표현하지 않습니다. 기존 홍픽종목과 차트 작도는 유지됩니다.

원저자·기관, 선정 논리, 적용 범위와 미검증 항목을 각 신호에 표시합니다. 오닐 가격·거래량 필터는 종가 신고가 돌파 + 직전 50일 평균 거래량 1.4배 + 돌파 기준 위 5% 이내로 변경했습니다. 252일 고가는 앱의 저항 대용 기준이며 정식 베이스 패턴이나 CAN SLIM 전체를 검증하지 않습니다. 와일더 RSI 필터도 실패스윙 전체의 구현으로 주장하지 않습니다. 공식 강의·교육 자료 링크와 지지/저항 해설을 화면에 제공하며 원저자 개인의 현재 추천으로 표현하지 않습니다.


홍픽종목의 주봉 빗각 점수는 완료 종가 이하의 가장 가까운 지지 후보에만 부여합니다. 종가와의 거리가 5% 미만이면 최대 25점이며 종가 위 저항선은 제외합니다. Codex 픽은 계속 빗각 가점 없이 계산하고, 저항 참고 설명에 사용할 전체 최근접 레벨은 별도 보존합니다.


주식 차트 페이지 맨 아래에 홍픽종목 / Codex 픽 전체 순위 TOP10을 표시합니다. 픽을 누른 출처에 맞춰 탭이 선택되며 다른 종목을 누르면 해당 차트와 지표로 이동합니다. 현재 차트 종목은 목록에서 강조됩니다.


뒤로가기·앞으로가기 시 브라우저 기록 항목별 스크롤 위치를 복원합니다. 목록 수집·렌더링이 끝난 뒤 다시 맞추며 사용자 스크롤·터치·키 입력이 시작되면 자동 복원을 중단합니다. 새 메뉴로 이동할 때는 기존대로 맨 위에서 시작합니다.


## 빗각 매매자리 (6.6.2)

홈의 매매자리 TOP5와 홍픽종목의 전용 필터는 주봉·일봉에서 ③ 이후 지지 접근과 최근 반등 확인을 별도로 표시합니다. `entry_signals.js`는 접촉일 당시까지 알려진 완료 봉으로 채널을 만들며, 이후 2거래일 이내 접촉봉 고가를 종가로 넘는지 검증합니다. 초기 ③은 2봉 탐색으로 잠정 표시합니다. 이미 5% 이상 지지에서 멀어졌거나 위 저항 여유 3% 이하, 지지 이탈이면 빗각 점수를 주지 않습니다. 정규 봉 확인 후 3거래일까지 유효합니다. 차트는 탐지 채널을 고정해 같은 자리를 보여줍니다. 대상은 기존 한국·미국 거래대금 TOP50 주식이며 시장 전체 실시간 알림은 아닙니다. 일봉 수집 캐시는 30분으로 조정했습니다.


첫 눌림 조건을 위해 동일 레벨의 ③ 이후 이전 접촉은 제외하고 ③ 이후 주봉 26봉·일봉 100봉 범위로 제한합니다. 주봉 라벨이 월요일인 제공원에서도 그 주 금요일 종료 전에 해당 봉의 값을 알려진 데이터로 취급하지 않습니다.
